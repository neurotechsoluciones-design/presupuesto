# Imágenes de Lorena Fit

Esta carpeta contiene los recursos visuales de la propuesta de Lorena Fit.

## Dónde subir las fotografías
Subí aquí las imágenes aprobadas para utilizar en la propuesta: portada, fotografías de Lorena, imágenes de programas, clases y materiales complementarios.

## Nombres sugeridos
- `hero-lorena.webp` — fotografía principal de portada.
- `lorena-retrato.webp` — fotografía de presentación.
- `programa-reto-21-dias.webp`
- `programa-fuerza-4-semanas.webp`
- `programa-movimiento-6-semanas.webp`
- `programa-campana.webp`
- `entrenamiento-clase.webp`
- `complementos-equipamiento.webp`

## Recomendaciones
- Usar nombres en minúscula, sin espacios ni tildes, separados con guiones.
- Preferir WebP o AVIF para fotografías y PNG/SVG para logos cuando corresponda.
- Conservar los originales y sus permisos de uso.
- Evitar subir imágenes personales no autorizadas.
- Las imágenes se referencian desde HTML o CSS como `./assets/images/nombre.webp` o `assets/images/nombre.webp`, según la ubicación del archivo que las utilice.
